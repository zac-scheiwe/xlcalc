## xlcalc

Calculations bit-for-bit identical to Excel 2024 for Windows (64-bit). Includes VBA, an Excel object model, pivot tables, charts, Solver, .xll add-ins and xls/xlsx/xlsb/xlsm/csv files.

### Install

```
cargo install xlcalc-cli
```

This installs the `xlcalc` console. Type `help` inside it to list the commands.

There is a ZIP of golden test cases attached to the releases. Contributions are welcome. I'm looking to improve coverage.
